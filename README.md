# The AfricaN (Digital Continental Broadsheet)

A premier pan-African digital news platform and broadsheet publication featuring breaking news dispatches, in-depth investigations, judicial rulings, entertainment, sports, cultural trends, interactive multimedia, real-time author editing studio, and high-impact animated advertisements.

---

## 🌟 Key Features

- **Editorial Sections**: Top Stories, Politics & Governance, Scandals & Whistleblowers, Gossip & Whispers, Entertainment & Celebrity, Technology & Innovation, Sports Arena & Football, Science & Health, Arts & Culture, and Club Madness.
- **Author Control & Studio**: Integrated live author studio allowing authors to:
  - Create, publish, update, and delete stories.
  - Manage and edit website categories, section titles, navigation bar order, and visibility.
  - Customize masthead typography, styling, taglines, and dispatches.
  - Update real-time flash tickers and Kenyan nightlife/club trends.
- **Dynamic 3D/4D Ad Innovations**: Continuously rotating 3D header ad cube next to the masthead logo, companion interactive sidebar ad units, and sponsor spotlights.
- **Nightlife & Trending Culture**: Dynamic Nairobi & Continental club trend tracking with live vibe metrics.
- **Responsive Architecture**: Built with modern React and Tailwind CSS for mobile, tablet, and high-resolution desktop viewports.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Lucide React Icons
- **State & Persistence**: React Context API + LocalStorage Newsroom Database

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or newer)
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/weisei-clintoo/the-AfricaN.git

# Navigate into the project directory
cd the-AfricaN

# Install dependencies
npm install
```

### Running the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) or [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production

```bash
npm run build
```
